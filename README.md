# GREENROOM v0.7

GitHub Pages向け。既存の `index.html` を更新します。v0.6からのデータ形式は保持。

- jungle背景：ウォームグレー帯・上方グラデーション。settings → jungle backgroundで位置、高さ、色、濃度を編集・保存。
- 配置時に横スクロールバー追加。ドラッグで植物を移動、サイズはスライダーのみ。
- fit plant時に縮小画面の下部UIガイドを表示。
- wander選択後は対象のみ最前面、その他を減光。対象植物の透明度に基づいてタップ判定し、対象以外のタップで解除。破線なし。
- スポットライトは通常レイヤーや配置データを変更しない。

## 注意
Safari実機での検証は未完了です。必ずsettings → dataからバックアップを保存してから更新してください。
